allOf

Six renderers all showing their representations of the same OAS specification.

In this case, the spec shows schemas making use of 'allOf' and 'oneOf'. 'allOf' is fairly simple so the only stand-out is Sourcey, which does not render schemas straight into path sections. 'oneOf' is much more difficult to render thoroughly and shows where the six contenders differ.

OpenAPI Explorer is the best at 'oneOf' here. Examples are always called "Example-n" but that is a minor complaint.

RapiDoc does a great job, but the project appears to be dead.

Redoc does not show schema summaries or descriptions.

Scalar shows the schema's description but you cannot change the example from that of the first schema.

Sourcey does not render schemas in path result sections.

Zudoku much like Scalar, displays the schemas very well but does not show all the examples.
